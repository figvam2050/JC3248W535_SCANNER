# 🔍 Сервісний документ: Автономний сканер-емулятор протоколів інверторів (JC3248W535_SCANNER)

**Пристрій:** Guition JC3248W535 / JC3248W535C (ESP32-S3, 3.5" IPS 320x480, MicroSD, Audio)  
**Інтерфейс підключення:** Порт P1 (JST 1.25 4-pin) -> Ізольований модуль TTL-RS485 з автоконтролем напрямку  
**Призначення:** Повністю автоматичне діагностування, захоплення сирого логу запитів інвертора та тестова емуляція батареї без участі людини.

---

## 🚀 1. Інструкція «В один клік» (Для не-інженерів)

1. **Крок 1:** Вставити кабель RJ45 у порт **`BMS`** або **`RS485`** будь-якого інвертора (Deye, Solis, Anenji, Felicity, Luxpower тощо).
2. **Крок 2:** Увімкнути екранчик кнопкою живлення (або підключити будь-який PowerBank).
3. **Крок 3:** Спостерігати за автоматичними етапами на великому кольоровому екрані:
   * 🟡 **Жовтий екран:** `[ 🔍 СКАcheckУВАННЯ ШИНИ... ]` — підбір швидкості 9600 / 19200 / 115200.
   * 🔵 **Синій екран:** `[ ⚡ ЗАПИС ЛОГУ ТА ТЕСТОВА ЕМУЛЯЦІЯ... ]` — прилад фіксує запити та безпечно відповідає інвертору за 2 віртуальні АКБ.
   * 🟢 **Зелений екран (через 2 хвилини) + звуковий сигнал:** `[ ✅ ТЕСТ ЗАВЕРШЕНО! ]`.
4. **Крок 4:** Вимкнути прилад, витягти кабель і віддати картку пам'яті MicroSD інженеру на аналіз.

---

## 🧠 2. Архітектура автоматичного розпізнавання протоколів

Прилад має вбудовану матрицю розпізнавання сигнатур інверторів:

1. **Deye / Sunsynk / Luxpower / Pylontech:**
   - Швидкість: 9600 8N1
   - Опитування: Адреса `0x01` (Master), Регістри `0x0000`..`0x0027` (FC03 Read Holding)
   - Емуляція: Стандартний 83-байтний фрейм Pylontech/Vision
2. **Huawei ESM (промислові системи):**
   - Швидкість: 9600 8N1
   - Опитування: Адреси `0xD6` (214), `0xD7` (215)
   - Емуляція: Специфічний бінарний блок регістрів Huawei ESM
3. **Solis (Ginlong):**
   - Швидкість: 9600 або 19200 8N1
   - Опитування: Специфічні блоки Modbus RTU
4. **Anenji / Axpert / Voltronic:**
   - Швидкість: 2400 / 9600
   - Опитування: ASCII або кастомний Modbus
5. **Невідомий / Новий протокол (Raw Logger):**
   - Автоматичний перехід у режим чистого цифрового осцилографа-рекордера.
   - Запис усіх вхідних байтів із точними мітками часу в мілісекундах.

---

## 💾 3. Що зберігається на MicroSD

Кожна сесія зберігається в окремий файл із послідовним номером:  
`/inverter_test_01.log`, `/inverter_test_02.log`...

Вміст логу містить:
1. Сирі HEX-дампи всіх запитів від інвертора.
2. Точний таймінг між пакетами (ms).
3. Звіт про те, яку відповідь прилад відправив і чи продовжив інвертор обмін (чи зникла аварія зв'язку на табло інвертора).
