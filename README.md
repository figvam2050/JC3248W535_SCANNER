# 🔍 Автономний сканер-емулятор протоколів інверторів (JC3248W535_SCANNER)

**Пристрій:** Guition JC3248W535 / JC3248W535C (ESP32-S3, 3.5" IPS 320x480, MicroSD, Аудіо NS4168)  
**Інтерфейс підключення:** Порт P1 (JST 1.25 4-pin) ➔ Модуль TTL-RS485 (RX=GPIO 44, TX=GPIO 43) ➔ Порт BMS інвертора (RJ45)  
**Призначення:** Повністю автоматичне діагностування («чорний ящик»), визначення протоколу опитування інвертора, тестова емуляція батареї 15S LiFePO4 та запис сесій обміну на MicroSD без участі оператора.

---

## 🚀 1. Інструкція для виїзного тестування (100% Hands-Free)

Монтажнику чи оператору **не потрібно нічого налаштовувати і не потрібно натискати жодних кнопок**:

1. **Крок 1:** Вставити кабель RJ45 у порт **`BMS`** або **`RS485`** будь-якого інвертора (Deye, Solis, Luxpower, Growatt, Anenji, Felicity тощо).
2. **Крок 2:** Подати живлення на екранчик (підключити USB-кабель від будь-якого PowerBank або блоку 5V).
3. **Крок 3:** Спостерігати за автоматичними етапами на кольоровому 3.5" дисплеї:
   * 🟡 **Жовтий статус:** `[ 🔄 SEARCHING INVERTER ON BMS PORT... ]` — автоперебір швидкостей 9600 ➔ 19200 ➔ 115200 ➔ 2400.
   * 🔵 **Синій статус (60 сек):** `[ ⚡ TESTING: Deye / Pylontech (58s left) ]` — інвертор знайдено! Прилад фіксує запити, безпечно відповідає за віртуальну батарею 15S LiFePO4 і перевіряє реакцію інвертора (`LINK OK!`).
   * 🟢 **Зелений статус + Звукова мелодія:** `[ ✅ TEST COMPLETE! POWER OFF SAFE ]` — тест завершено, зв'язок підтверджено, лог збережено на MicroSD.
4. **Крок 4:** Вимкнути живлення, від'єднати кабель і передати прилад із карткою пам'яті інженеру для аналізу.

## 🧠 2. Вбудована матриця розпізнавання протоколів інверторів

Прилад автоматично визначає сигнатуру опитування за адресою та діапазоном регістрів:

1. **Deye / Sunsynk / Luxpower / Pylontech:**
   * Швидкість: `9600 8N1`
   * Опитування: Адреса `0x01` (Master), Регістри `0x0000`..`0x0027` (FC03 Read Holding або FC04 Read Input).
   * Емуляція: Стандартний блок телеметрії 15S (52.50V, 0.0A, 85% SOC, 100Ah, комірки по 3500 mV).
2. **Huawei ESM (промислові літієві модулі):**
   * Швидкість: `9600 8N1`
   * Опитування: Специфічні адреси `0xD6` (214) або `0xD7` (215).
3. **Solis (Ginlong RHI / S5 / S6):**
   * Швидкість: `9600` або `19200 8N1`
   * Опитування: Діапазон регістрів `0x3000`..`0x3500`.
4. **Growatt Modbus (SPF / SPH):**
   * Швидкість: `9600 8N1`
   * Опитування: Адреса `0x01`, регістри `0x0020`..`0x0050` (протокол Lithium L01 / L51).
5. **Універсальний Modbus RTU (Anenji, Felicity, Must, PowMr, Easun тощо):**
   * Захоплення будь-якого 8-байтного запиту FC03/FC04 з валідною чексумою CRC16.
6. **Невідомий / Кастомний протокол (Raw Blackbox):**
   * Прилад записує абсолютно всі вхідні байти з мілісекундними інтервалами у файл сесії для комп'ютерного реверс-інжинірингу.

## 💾 3. Структура файлів на MicroSD

Кожен запуск створює окремий файл сесії з автоматичною нумерацією:  
`/inverter_scan_01.log`, `/inverter_scan_02.log` ... `/inverter_scan_99.log`.

**Приклад вмісту лог-файлу:**
```text
=== INVERTER BMS SCANNER SESSION #03 STARTED ===
Format: [Time_ms] [Baud] [Status] [Len] HEX_BYTES
[12450] [9600] [CRC_OK] [8] 01 03 00 00 00 27 05 D0
[12455] [9600] [CRC_OK] [83] 01 03 50 14 82 00 00 0D AC 0D AC ... B4 A1
[13460] [9600] [CRC_OK] [8] 01 03 00 28 00 10 C4 02
=== INVERTER BMS SCANNER SESSION STOPPED ===
```

* `[Time_ms]` — точний час у мілісекундах від старту приладу (дозволяє виміряти паузи між запитами).
* `[CRC_OK / CRC_ERR]` — валідація контрольної суми кадру.
* `HEX_BYTES` — чисті байти запитів інвертора та надісланих відповідей емулятора.
